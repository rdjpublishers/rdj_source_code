Free source packs and design resources, explained

RDJ Source Codes is a small library of free downloadable zip packs that I put together and maintain myself as part of RDJ Publishers, my independent web studio in Tamil Nadu, India. Each entry pairs a preview image or animated GIF with a single zip file, so you can see what a pack looks like before you download it. There is no account to create and nothing to pay.

What kinds of packs are in the library?

Packs are grouped into six categories, which you can browse with the tabs above the gallery:

  • Templates — starting points for web pages such as portfolios and landing pages, written in plain HTML and CSS so they are easy to read and change.
  • Icon Packs — sets of glyphs, usually SVG, for interfaces, presentations and slides.
  • UI Kits — reusable interface pieces such as buttons, loaders and cards, with animated previews where that helps.
  • Presets — colour and look presets for photo and video editing, such as LUT packs.
  • Fonts — typefaces packaged for desktop or web use.
  • Wallpapers — textures and backgrounds sized for phones and desktops.

How to download a pack

Open any card to see a larger preview, its category and its tags. Press the download button and your browser saves the zip file. Use the search box to match a title, category or tag, and the sort menu to order results by newest, oldest, name or most downloaded.

Using a downloaded zip

Unzip the file with the built-in tool on your computer or phone. Open the folder and look for a short readme or the main file first. For a template, open index.html in a browser to see it running, then edit the text and colours in any code editor. For fonts, install the files on your device or upload them with your site. For presets, import them into your editing app using its preset or LUT menu.

Tips for getting the most from a pack

  • Keep an untouched copy of the original zip so you can start over if an edit goes wrong.
  • Rename files and change the placeholder text and colours so your result looks like your own work.
  • Test templates on a phone as well as a desktop, since most visitors use small screens.
  • If you plan to use a pack in paid or client work, check for a licence note in the download and write to me if anything is unclear.

Troubleshooting

If a download does not start, make sure your browser is not blocking downloads for this site, then try again. If a zip will not open, download it again, since an interrupted transfer can leave a damaged file. If a preview does not load, refresh the page or try another connection. If none of that helps, send me the pack name and your browser and device through the Contact page and I will look into it.
